# **App Name**: Chiang Mai Accounting Experts

## Core Features:

- Bookkeeping and Tax Preparation: Automate bookkeeping and tax preparation, ensuring compliance with Thai regulations. Connects to Clero accounting software for seamless data integration and up-to-date financials.
- Automated Notifications: Configure and send automated notifications through Line
- Company Registration: Streamline the company registration process for various legal entities.
- Visa and Work Permit Assistance: Provide guidance and support for foreigners seeking visas and work permits in Chiang Mai.

## Style Guidelines:

- Primary color: Deep sky blue (#3498DB) to convey trust and reliability in financial services.
- Background color: Light gray (#F0F2F5), providing a clean and professional backdrop.
- Accent color: Emerald green (#2ECC71) for highlighting key services and calls to action, giving a sense of growth and prosperity.
- Body and headline font: 'Kanit' sans-serif for a modern Thai feel.
- Use consistent, professional icons in a flat style to represent accounting services.
- Maintain a clean and structured layout for easy navigation.
- Incorporate subtle transitions for a modern user experience.
