# icaccservice-web

เว็บไซต์บริษัท IC Accounting & Service สำหรับให้บริการรับทำบัญชี จดทะเบียนบริษัท และบริการที่เกี่ยวข้องในจังหวัดเชียงใหม่

## การเริ่มต้นใช้งาน

โปรเจกต์นี้สร้างด้วย Next.js และใช้เทคโนโลยี:
- React
- Tailwind CSS
- ShadCN UI
- AOS (Animate on Scroll)
- Genkit (AI Services)

คุณสามารถเริ่มพัฒนาได้โดยใช้คำสั่ง:
```bash
npm run dev
```
